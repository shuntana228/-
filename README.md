# 📊 財務分析ツール - Financial Analysis Tool

証券コードを入力すると、該当企業の財務分析結果をグラフィカルに表示するPythonツールです。

## 🌟 機能

このツールは以下の分析グラフを自動生成します：

1. **株価チャート & 移動平均線**
   - 終値の推移
   - 5日、25日、75日移動平均線

2. **ボリンジャーバンド**
   - 上限・下限バンド
   - ボラティリティの可視化

3. **出来高分析**
   - 日次出来高
   - 出来高移動平均（20日）

4. **RSI（相対力指数）**
   - 買われすぎ・売られすぎの判定
   - 70（買われすぎ）/ 30（売られすぎ）ライン表示

5. **MACD（移動平均収束拡散法）**
   - トレンド転換のシグナル
   - MACDライン、シグナルライン、ヒストグラム

6. **価格変動率分布**
   - 日次リターンのヒストグラム
   - 平均値・中央値の表示

7. **統計情報サマリー**
   - 現在価格、変動率
   - 高値・安値
   - ボラティリティ
   - シャープレシオ
   - 最大ドローダウン

8. **ローソク足チャート**
   - 90日間のローソク足
   - 移動平均線オーバーレイ
   - 出来高表示

## 🚀 使用方法

### 基本的な使用方法

#### コマンドライン引数で証券コードを指定

```bash
python financial_analyzer.py 7203
```

#### インタラクティブモード

```bash
python financial_analyzer.py
```

実行後、証券コードの入力を求められます。

### 対応している証券コード

#### 日本株
4桁の証券コード（自動的に`.T`が付加されます）

- `7203` - トヨタ自動車
- `6758` - ソニーグループ
- `9984` - ソフトバンクグループ
- `7974` - 任天堂
- `6501` - 日立製作所

#### 米国株
ティッカーシンボルをそのまま入力

- `AAPL` - Apple Inc.
- `GOOGL` - Alphabet Inc.
- `MSFT` - Microsoft Corporation
- `TSLA` - Tesla Inc.
- `AMZN` - Amazon.com Inc.

#### その他の市場
対応するティッカーシンボルを入力（例: `0700.HK` for Tencent）

2. `{証券コード}_candlestick.png` - ローソク足チャート

## 📈 分析指標の説明

### テクニカル指標

- **移動平均線 (MA)**: 価格の平均的なトレンドを示す
- **ボリンジャーバンド**: 価格のボラティリティと相対的な高値・安値を示す
- **RSI**: 0-100の範囲で、70以上は買われすぎ、30以下は売られすぎを示す
- **MACD**: トレンドの方向性と強さを示す

### 財務指標

- **PER (株価収益率)**: 株価が1株当たり利益の何倍かを示す
- **PBR (株価純資産倍率)**: 株価が1株当たり純資産の何倍かを示す
- **ROE (自己資本利益率)**: 企業の収益性を示す
- **配当利回り**: 株価に対する年間配当金の割合

### リスク指標

- **ボラティリティ**: 価格変動の大きさ（標準偏差）
- **シャープレシオ**: リスク調整後のリターン
- **最大ドローダウン**: 最高値からの最大下落率

## 🔍 カスタマイズ

### データ取得期間の変更

`financial_analyzer.py`の`main()`関数内で期間を変更できます：

```python
analyzer.fetch_data(period="5y")  # 5年間のデータ
```

利用可能な期間:
- `1mo` - 1ヶ月
- `3mo` - 3ヶ月
- `6mo` - 6ヶ月
- `1y` - 1年
- `2y` - 2年（デフォルト）
- `5y` - 5年
- `10y` - 10年
- `max` - 最大期間

### ローソク足の表示日数変更

```python
analyzer.plot_candlestick(days=180)  # 180日間表示
```

## ⚠️ 注意事項

2. **リアルタイム性**: データには15-20分の遅延がある場合があります
3. **投資判断**: このツールは情報提供のみを目的としており、投資助言ではありません

## 🛠️ トラブルシューティング

日本語の表示はシステムフォントに依存します。文字化けする場合は、フォント設定を調整してください。
